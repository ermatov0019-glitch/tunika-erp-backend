1

CSS @media print yordamida chop etish (Eng oddiy va ishonchli usul)

Ushbu usul kompyuter va mobil telefonlardagi brauzerning standart "Chop etish" xizmatidan foydalanadi. Buning uchun chek kengligini belgilab, chop etish vaqtida ortiqcha tugmalarni yashiruvchi CSS yozish kerak. Biz buni ushbu sahifada tayyor qildik:

@media print { body { background: white; color: black; margin: 0; } .no-print, button, .controls-card, header { display: none !important; } .receipt-paper { width: 100% !important; box-shadow: none !important; } }
2

Android uchun RawBT ilovasi orqali to'g'ridan-to'g'ri chop etish

Agar sizda termal printer Bluetooth orqali ulangan bo'lsa va brauzerning chop etish dialogi printeringizni tanimasa, Android qurilmangizga RawBT ilovasini yuklab oling. Keyin, veb sahifangizga quyidagi maxsus havolani joylashtiring. Bu havola bosilganda brauzerdan chek matnini to'g'ridan-to'g'ri printerga yuboradi:

function printWithRawBT(text) { const encodedText = encodeURIComponent(text); const intentUrl = `intent:${encodedText}#Intent;scheme=rawbt;package=ru.a402d.rawbtprinter;end;`; window.location.href = intentUrl; }
3

Web Bluetooth API (Kompyuter va Android Chrome uchun)

"Bluetooth Printer" tugmasi brauzerdan printerga to'g'ridan-to'g'ri simsiz ulanib, ESC/POS buyruqlarini yuboradi. Hech qanday qo'shimcha ilovasiz ishlaydi (iOS tizimlarida Web Bluetooth brauzerlarda bloklangan bo'lishi mumkin).
